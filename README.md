# Wev-developer Portfolio

**[Смотреть сайт](https://8wuluwulu.github.io)** Это мой личный сайт-портфолио, который служит центральным хабом для всех моих проектов. Сайт разработан с нуля без использования сторонних UI-библиотек или тяжелых JS-фреймворков. Здесь просто описание моей деятельность и проектов.

## Стек технологий

* **Разметка:** HTML5 (Семантическая)
* **Стилизация:** CSS3 (Variables, Grid, Flexbox, Animations)
* **Логика:** Vanilla JavaScript
* **Инструменты:** Git, GitHub Pages, Chrome DevTools

## AI-Assisted Workflow

При создании этого сайта я активно применял ИИ-инструменты. Нейросети использовались для:
1.  Генерации базового бойлерплейта и структуры сетки.
2.  Подбора гармоничной цветовой палитры (Deep Blue/Neon).
3.  Парного программирования при отладке сложных багов (например, перекрытие z-index в мобильном меню).

## Локальный запуск

Проект является статичным и не требует сборки.
1. Клонируйте репозиторий: `git clone https://github.com/8wuluwulu/8wuluwulu.github.io.git`
2. Откройте файл `index.html` в любом браузере.
